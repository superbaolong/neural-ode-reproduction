# MNIST 公平对比：seed 0 与 seed 1

两次运行均使用相同的模型、数据、batch size 64、5 个 epoch、Adam 学习率 1e-3 和 FP32 CUDA 训练；只有随机种子不同。

| 模型 | seed=0 最佳 | seed=1 最佳 | 两个 seed 的最佳均值 |
|---|---:|---:|---:|
| ODENet | 98.33% | 97.56% | 97.95% |
| ResNet | 91.01% | 93.35% | 92.18% |

第 5 轮最终准确率分别为：ODENet `98.33% / 94.57%`，ResNet `87.51% / 93.35%`（顺序为 seed=0 / seed=1）。这说明 5 个 epoch 时训练轨迹仍有明显随机波动，尤其是 ODENet 的自适应求解器 NFE 和测试准确率会随参数初始化变化。

当前只有两个 seed，均值仅用于展示统计方法；正式报告建议至少使用 3 个 seed。
